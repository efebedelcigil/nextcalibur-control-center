# Nextcalibur 0.7.2

Games found where they really are, and a language change that changes words only.

## Fixed

- **Fall Guys never switched to Gaming**: its folder did not say which program
  is the game (FallGuys_client_game). Windows' own list of games played
  (Game Bar) now names it.
- **A game left behind by an uninstall was listed**: an Epic manifest left on
  disk, or a program no longer there, is no longer a game. Epic games are
  checked against Epic's own installed list.
- **"Check now" on a pre-release said it was up to date**: 0.7.1-beta2 took
  itself for 0.7.1. The installed version now keeps its pre-release part.
- **Changing the language rebuilt the Settings page**: settings were reloaded
  and rows rebuilt, with handlers firing on the way. Now only the words change.
- **The Efficiency scan kept saying "not scanned yet"** when it found nothing;
  it now says nothing was busy.

## New

- **Microsoft Store and Game Pass games**, and games from their own installers
  that Windows has seen played, are found by Scan for games.
- **Installed apps crossed**: each game says whether Windows' Installed apps
  lists it (shown only; nothing is dropped for it).
- **Open file location** beside every game, program rule and Efficiency program.
- **The program rules switch is logged**, and the card says when rules are off
  while games are on the list.
