# Nextcalibur 0.5.5

## Zero-bottleneck gaming & heavy workload architecture

A laptop control center lives alongside your games and workloads; it must never compete with them for system resources or cause frame drops. 0.5.5 introduces a comprehensive zero-bottleneck architecture:

- **Borderless windowed & fullscreen game detection:** Intelligently detects when a game or immersive application occupies the screen (`IsForegroundFullScreenOrBorderless`), while explicitly excluding Windows desktop components, taskbar trays (`Shell_TrayWnd`, `Shell_SecondaryTrayWnd`), and Nextcalibur itself.
- **Dynamic process priority scheduling:** While running in the background, minimized, or deactivated, Nextcalibur automatically lowers its own process priority to `BelowNormal` via native Win32 `SetPriorityClass` using a pseudo-handle (with zero memory allocations and zero handle accumulation). The moment you bring Nextcalibur to the foreground, it instantly restores `Normal` priority. The Windows thread scheduler unconditionally prioritizes games, compilers, and rendering tasks over background maintenance.
- **Suppressed EC mailbox polling (eliminated SMI frame drops):** Embedded controller mailbox reads stop completely while playing games or during heavy multi-core CPU load. Each mailbox query triggers a 21 ms System Management Interrupt (SMI) that stops all CPU cores; suppressing these queries eliminates mid-game micro-stutters and frame drops.
- **Quiet PawnIO MSR overheat watching & deferred alerts:** Overheat monitoring during games shifts quietly to direct MSR register reads via PawnIO (which execute in nanoseconds with zero SMIs and zero core freezes). Thermal alert notifications are held quietly in memory and presented once you finish your game or workload.
- **Unconditional stand-down:** Background memory trimming (`MemoryTrimmer`) and Windows fault remediation (`WindowsFaults`) stand down completely during gaming and heavy workloads.

## Discrete GPU sleep protection in Hybrid mode

In Hybrid graphics mode, background health and sensor checks now verify `DevicePowerState.MostRecent()` before inspecting the NVIDIA discrete GPU. If the card is in runtime D3 power sleep, NVML is never queried, preventing unwanted wakeups, battery drain, and thermal spikes.

## Deep memory & resource leak eradication

Every resource lifecycle across the application was audited:

- **Child process handle wraps:** All elevated relaunch and shell-fallback child processes (`Elevation.cs`, `Unelevated.cs`) are wrapped in `using var`, releasing OS process handles immediately upon process termination.
- **Static event rooting eliminated:** The `Strings.Changed` static event handler in `MainWindow` was converted from an anonymous lambda to a named method group and explicitly unsubscribed on close (`Strings.Changed -= OnLanguageChanged;`), preventing static rooting of the main UI window in memory.
- **Teardown discipline:** Static modal dialog owner references (`Dialogs.Owner = null`) and closure delegates (`WindowsFaults.IsFaultEnabled`) are cleanly cleared on window close.
- **Deterministic timer disposal:** Auxiliary DispatcherTimers (`_settingsSaveDelay`, `_gpuCooldown`, `_lightingThrottle`) are explicitly stopped alongside the primary sampling timers on teardown.
- **Unmanaged GDI & mutex cleanup:** The unmanaged GDI icon handle (`HICON`) encapsulated by custom tray icons is safely disposed in `TrayPresence.Dispose()`, and the single-instance synchronization Mutex in `App.xaml.cs` is cleanly disposed on application shutdown.
- **Zero-allocation hot paths:** Hot-path array allocations in `CpuPowerReader` were eliminated by reusing pre-allocated MSR input/output buffers.

## Asynchronous dispatcher & UI thread hardening

- **Top-level `try/catch` exception boundaries:** In WPF, unhandled exceptions escaping `async void` handlers or timer callbacks can bypass dispatcher error handling and crash the process. All UI `async void` methods (`CheckForUpdatesByHand`, `OfferUpdate`, `OfferDependency`, and `Sample`) are enclosed in complete top-level `try/catch` boundaries.
- **Installer cleanup exception safety:** Temporary file cleanup in `DependencyManager.InstallAsync` catches `UnauthorizedAccessException` and `SecurityException` alongside `IOException`, preventing transient antivirus file locks from interrupting installation flows.

## Startup preferences & installer accuracy

- **Start with Windows preference:** Settings and the installer wizard allow choosing between starting minimized in the notification tray or opening with the main window displayed on screen.
- **Tray tooltip safety:** Clamped tray tooltip text to 63 characters to prevent Windows Forms `NotifyIcon` length exceptions.
- **Installer dependency checklist:** The Inno Setup wizard accurately probes whether the .NET 8 desktop runtime and PawnIO driver are already installed or missing before presenting component checkboxes.
- **Live .NET runtime updates:** Tested and verified genuine silent .NET 8.0.31 updates on physical hardware with Authenticode and SHA-256 verification.
