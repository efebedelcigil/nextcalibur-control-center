# Nextcalibur 0.5.7

## Inno Setup Uninstaller, Trace Cleanup & Single Control Panel Entry

This release resolves the installer and uninstaller issues reported in 0.5.6:

- **Official Inno Setup Uninstaller:** Nextcalibur now uses Inno Setup's uninstaller (`unins000.exe`) as its primary Windows Add/Remove Programs entry. The uninstaller runs with full Turkish and English localization.
- **Settings & Trace Cleanup Prompt:** When uninstalling, Inno Setup prompts the user with a clear question: *"Nextcalibur ayarlarınızı, günlük dosyalarını ve artık sistem kayıtlarını da silmek istiyor musunuz?"* (*"Do you want to delete your Nextcalibur settings, log files, and temporary trace files as well?"*). If accepted, `%APPDATA%\Nextcalibur`, power plans, and all machine traces are cleanly purged.
- **Single Control Panel & Settings Entry:** Eliminated duplicate entries in Control Panel and Windows Settings. Duplicate Velopack `HKCU` registry entries are actively cleaned on installation and elevated startup, ensuring exactly one clean **Nextcalibur Control Center** entry exists.
- **Fixed Finish Page Path Error:** Fixed the *"belirtilen yolu bulamıyor"* (*"The system cannot find the path specified"*) error when checking *"Launch Nextcalibur"* on the installer finish page by correctly targeting `{app}\current\Nextcalibur.exe` with its working directory configured.
- **Version Synchronization:** On elevated launch, Nextcalibur keeps the Inno Setup uninstaller's `DisplayVersion` synchronized with the running version across in-place Velopack updates.
