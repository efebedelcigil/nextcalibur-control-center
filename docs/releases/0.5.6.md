# Nextcalibur 0.5.6

## Windows Installed Apps & Control Panel registration

Nextcalibur is installed under Program Files (machine-wide for all users). This hotfix ensures Nextcalibur is properly registered in Windows Add/Remove Programs:

- **Windows Settings & Control Panel presence:** Registered under `HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\Nextcalibur`, appearing in **Settings › Apps › Installed apps** (and Control Panel › Programs and Features) with its application icon, publisher, version, and direct uninstall option.
- **Uninstallation via Windows UI:** Clicking *Uninstall* in Windows Settings or Control Panel invokes the uninstaller (`Update.exe uninstall`), cleanly executing the uninstallation dialogs (asking about power plans, Windows repairs, and the PawnIO driver) and removing shortcuts, scheduled tasks, and machine traces.
- **Self-update maintenance:** On elevated startup, Nextcalibur verifies and updates its `HKLM` uninstall registration to match the running version, ensuring the version displayed in Windows Settings stays accurate across in-place updates.
- **Clean removal:** The uninstaller explicitly cleans up the `HKLM` uninstall registration, leaving no orphaned entries behind.
- **Installer repair detection:** The Inno Setup wizard checks both `HKLM` and `HKCU` to accurately detect existing installations and offer clean in-place repairs.
