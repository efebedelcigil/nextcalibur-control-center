# Nextcalibur 0.5.12

Updates can be put off once, not refused - and they are found without anybody clicking.

## Changed

- **Every copy updates itself.** A new release was found only by
  "Check for updates now" in practice: the automatic check ran a minute
  after start and then every six hours. Now it runs every fifteen minutes
  and a minute after every wake from sleep. Until something is published
  GitHub answers "not modified" with no body, so the extra checks cost next
  to nothing.
- **Offered once, then installed.** A new release comes as a notification
  and a question, as before, and "no" is still an answer - once. The next
  time it comes up, six hours later or at the next start, the window shows
  it with a single *Update now* button and installs it. The question now
  says why: this application writes to the firmware and runs as
  administrator, and each release fixes those parts. The second offer waits
  while a game or a presentation has the screen. While a graphics mode
  change is waiting for Windows to restart, the update is downloaded and
  goes in at that restart: restarting Nextcalibur first would drop the change.
- **The two update switches are gone** from the Settings page, the tray
  menu and the tour. *Check for updates now* stays.
- The PawnIO driver and .NET runtime checks keep their pace - at most every
  six hours - and still ask before installing anything.

The first update to arrive this way is the one after 0.5.12: a copy on
0.5.11 or earlier still finds 0.5.12 on its own schedule, or with *Check for
updates now*, and asks as before.
