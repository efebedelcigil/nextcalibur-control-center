# Nextcalibur 0.5.12

Updates are no longer optional, and no longer wait for somebody to click.

## Changed

- **Every copy updates itself.** A new release was found only by
  "Check for updates now" in practice: the automatic check ran a minute
  after start and then every six hours. Now it runs every fifteen minutes
  and a minute after every wake from sleep. Until something is published
  GitHub answers "not modified" with no body, so the extra checks cost next
  to nothing.
- **Found means installed.** The release is downloaded in the background
  and the application restarts into it by itself - the window stays hidden
  if it was hidden. It waits while a game or a presentation has the screen,
  or a dialogue is open. While a graphics mode change is waiting for Windows
  to restart, the update is installed at that restart instead: restarting
  Nextcalibur first would drop the change.
- **The two update switches are gone** from the Settings page and the tray
  menu. *Check for updates now* stays, and installs at once with the
  progress in view.
- The PawnIO driver and .NET runtime checks keep their pace - at most every
  six hours - and still ask before installing anything.

The first update to arrive this way is the one after 0.5.12: a copy on
0.5.11 or earlier still finds 0.5.12 on its own schedule, or with *Check for
updates now*.
