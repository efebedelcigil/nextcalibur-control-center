# Nextcalibur 0.6.0

Heat, followed rather than compared; every risky change on the record, with
a restore point first; and nothing Casper-specific on a laptop that is not
a Casper.

## Heat

- **The heat warning says what is making it hot.** The three programs using
  the processor most over one second, or the programs NVIDIA lists on the
  card, are in the warning. From Gaming or Performance it has a button that
  switches to Office. The advice to clean the heatsink now says when it
  applies: hot with nothing heavy running.
- **Cool down before it gets hot** (on by default). The temperature is
  fitted over three minutes; when it is heading for the warning line, a
  notification says to press Fn+1 - the fan turbo - before it gets there,
  and once it has cooled, that the turbo can go off. The turbo is the
  embedded controller's own: nothing in the BIOS sets it from software
  (measured), and reaching the controller directly would race Windows' own
  driver, so the application reads it and suggests it, never sets it.
- **Emergency Office** (off by default): with that, hold the processor to
  the Office plan's 70% until it has cooled.
- **Programs heating the machine for nothing** are named: a background
  program keeping a core busy, flat, for fifteen minutes, or the graphics
  card busy with nothing on screen needing it. Nothing is ended; the
  notification opens Task Manager.
- **A plan that pins the processor is repaired.** The vendor's Gaming plan
  holds the performance cores' minimum state at 99%; it is set to 5% at
  start (measured harmless today, one change of the processor's own
  management away from 4 GHz at idle), the original kept, put back at
  uninstall if the repairs are not kept. Our own Office plan gets the
  vendor's Office ceiling, 70%.

## Safety and records

- **A restore point before every risky change**, ticked by default: the
  graphics mode, driver and runtime installs, the power-mode repair, the
  NDU fix, WinUtil. Windows' once-a-day limit is lifted for that one point
  and put back. Going on without one - unticked, or none made - is a second
  question that says it is not recommended, "no" by default.
- **An audit log**: each question, answer, restore point (with its number)
  and change, with its time and the Windows account, in a file only
  administrators can write - changed from outside, it is put back - and in
  Windows' event log, which keeps it after an uninstall.
- **Only on the laptop it was made for.** The machine is scanned at setup -
  the wizard says so if it is not a Casper Excalibur - and at every start,
  the verdict kept and a change of it logged. On any other laptop the
  system modes, plans, cooling, Fn shortcuts, lighting and graphics mode
  stay off, and Windows keeps its own settings.

## Keyboard

- **The Fn keys from an external keyboard**, off until switched on: the
  keyboard light (Fn+Space's order) and the system mode as shortcuts, any
  keys. Keys Windows, another program or a keyboard layout already uses -
  Ctrl+Alt+Q types @ on Turkish Q - are refused and the old ones kept; a
  conflict that appears later moves the shortcut to free keys and says so.

## Smaller

- One taskbar button with the pinned icon, from the tray and after a
  restart; the executable's Details tab says what it is and which version;
  our shortcuts carry the version in their comment.
- The window comes back on screen if it was hidden on a monitor since
  unplugged (0.5.11); the graphics mode reads right with a monitor and the
  lid shut (0.5.11).
