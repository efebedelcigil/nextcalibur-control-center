# Nextcalibur 0.5.8

## Fix GPU Switch Restart Prompt & Windows Privilege Adjustment

This release fixes the GPU mode switch to Discrete/Hybrid and restores reliable Windows system restarts:

- **GPU Switch Restart Prompt:** When switching graphics mode (e.g. from Hybrid to Discrete), Nextcalibur now immediately prompts the user with the restart confirmation dialog (*"Şimdi yeniden başlatılsın mı?"* / *"Restart now?"*) after firmware mode staging, rather than leaving the change silent behind the banner.
- **Fixed Win32 `TokenPrivileges` Struct Layout:** Fixed a 64-bit P/Invoke struct alignment bug where an 8-byte `long` field caused 4 bytes of padding in `TokenPrivileges`, corrupting the structure size to 24 bytes instead of the expected 16 bytes. This caused `AdjustTokenPrivileges` to fail with `ERROR_NOT_ALL_ASSIGNED` (1300) and prevented `SeShutdownPrivilege` from being enabled on the process token.
- **Reliable Windows Restart Fallback:** `RequestRestart()` now verifies privilege enablement via Win32 error checking, executes `ExitWindowsEx`, and incorporates an automatic fallback to `shutdown.exe /r /t 0` should Windows session isolation or third-party interference reject the user32 call.
- **Session End Firmware Mode Write:** Guarantees `WM_ENDSESSION` cleanly writes the display mode register (`0xFB00 / 0x0203`) to the Tongfang EC before rebooting.
