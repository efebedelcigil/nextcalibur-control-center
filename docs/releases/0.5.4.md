# Nextcalibur 0.5.4

## Türkçe

The whole application speaks Turkish or English: every page, every
dialogue, the tray menu, the tour's sixty-seven steps, the sentences the
library writes - a switch's summary, a verdict's reasons, the power modes'
descriptions - and the questions the uninstall asks. The first start takes
the language Windows is set to; *Settings › Behaviour › Language* changes
it at once and the choice is remembered. Mode names, brand names and the
product's name stay as they are in both.

The Turkish was written by the project and will be corrected as it is read;
a wrong word is an issue like any other.

## The language row

The corner button of the previous build is gone; the language lives on the
Settings page, first in the Behaviour group, as a two-way switch in the
style of the interval picker.

## Privacy

A *Privacy* button on the Settings page says in four lines what the
application does with data - nothing collected, nothing sent - and opens
the full policy (`docs/PRIVACY.md`, with the table of every request the
application ever makes) on a yes.

## Security

A review of the application as the thing an unelevated program running as
your account would attack - it runs as administrator, from a task, without
a prompt. Seven findings, all closed; `docs/SECURITY.md` has the rules.

- A copy outside Program Files - an earlier version's install in the
  profile, the portable zip - no longer gets the no-prompt tasks: the
  folder above it is yours, and a folder can be swapped from there. Such
  a copy is asked for administrator rights at every start and a banner
  says why; the installer moves it under Program Files for good. Tasks an
  earlier version registered for such a copy are removed at the next start.
- The task is registered through the Task Scheduler's interface, not via
  a file in the temporary folder that anything could rewrite in between.
- A downloaded installer (PawnIO) is verified with `WinVerifyTrust` - the
  signature must cover the file, not merely be present - and the signer
  matched exactly; it is written where only administrators can reach it,
  under a random name, and held open from the check to the end of the run.
  The wizard does the same from `{app}`.
- The uninstall's delayed script lives in the same protected place.
- Windows tools are run by full path; the current directory and `PATH`
  are never searched for programs or libraries.
- Settings, the lighting state and the log are not written through a
  junction or link in the profile; what is read from them is clamped.

## Smaller

- The on/off switches say *açık* / *kapalı* in Turkish, and are a little
  wider for it; the effect tiles fit a two-line name.
- The tour's card re-renders in the new language while it is open.
- Multi-paragraph dialogues keep their paragraphs (the exit question had
  lost its second one).
- The unelevated-era "grant sensor access" path - a second copy of the
  application widening a firmware permission - is gone; the application
  runs elevated and takes such a grant back at start.
- Two new tests: every key the code asks for exists in the dictionaries,
  and the English the library writes beside a key is the English in the
  dictionary.
