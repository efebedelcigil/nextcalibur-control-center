# Nextcalibur 0.5.2

## A proper installer

`Nextcalibur-Setup-0.5.2.exe` is a wizard: it asks where to install and does
the rest. The default is your own profile folder, and a folder your account
cannot write to is refused up front, because updates install there later
without asking for administrator rights. Velopack still does the installing
and the updating underneath; there is one entry in Add/Remove, and removing
it still asks what to keep.

## Updating, on your terms

A new release is found quietly and said once through the tray. Clicking the
notification - or the button that appears above the version in the corner, or
"Check for updates now" in the tray - brings the question: update to vX.Y.Z?
Yes downloads with a progress bar in the window's own dialogue and restarts
the application into the new version. No leaves the button for later and
nothing asks again until the next start.

## A restart you can cancel

A graphics mode switch that needs a restart now restarts the way Windows
does: applications with unsaved work get to object, you get Windows' own
"restart anyway / cancel" screen, and cancel means the mode does not change.
Nothing is written to firmware until the session is really ending.

## Every drive

Memory & Disk shows every fixed drive, not only the Windows one, and reads
them once a minute rather than every few seconds.

## Taskbar

One button, whether you started Nextcalibur from a pin, the Start menu or
Windows itself; the button minimises on a second click like any other.

## Small things

- Closing the window exits, after a question; the third caption button hides
  to the tray instead.
