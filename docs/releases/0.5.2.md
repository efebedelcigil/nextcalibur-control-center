# Nextcalibur 0.5.2

## A proper installer

`Nextcalibur-Setup-0.5.2.exe` is a wizard, in English and Turkish: it shows a
notice you have to accept, asks where to install and whether to start with
Windows, and does the rest. The default is your own profile folder, and a
folder your account cannot write to is refused up front, because updates
install there later without asking. One copy per machine: a second install
is refused until the first is removed. Velopack still does the installing
and the updating underneath; there is one entry in Add/Remove, and removing
it still asks what to keep.

## It runs as administrator now

The way the vendor's software does. You are asked once, on the first run;
after that a scheduled task starts Nextcalibur with those rights and no
prompt - from the Start menu, a pin, or at sign-in. This is what reading the
firmware, switching the graphics card and reading the processor's power all
need, and it retires the permission grant and the helper tasks of earlier
versions.

## CPU power

The processor's package power is shown beside its clock, through PawnIO - a
Microsoft-signed, open-source kernel driver that is yours to install. Without
it the number reads `--`. When it is missing or behind, Nextcalibur offers it:
downloaded from its own releases, its signature checked, installed quietly,
on a yes. The same mechanism will keep anything else the application comes
to depend on current.

## Updating, on your terms

A new release is found quietly and said once through a notification with an
*Update now* button. That, the button that appears above the version in the
corner, or "Check for updates now" in the tray, brings the question: update
to vX.Y.Z? Yes downloads with a progress bar in the window's own dialogue
and restarts the application into the new version. No leaves the button for
later and nothing asks again until the next start.

## A restart you can cancel

A graphics mode switch that needs a restart now restarts the way Windows
does: applications with unsaved work get to object, you get Windows' own
"restart anyway / cancel" screen, and cancel means the mode does not change.
Nothing is written to firmware until the session is really ending.

## Power Mode within the System mode

The Power Mode cards adjust within the mode - Office offers Efficiency and
Balanced, Gaming Balanced and Better performance, Performance Better and
Best - and choosing a mode puts its own overlay on. "Office with the processor
at full speed" can no longer be assembled by accident.

## Every drive

Memory & Disk shows every fixed drive, not only the Windows one, and reads
them once a minute.

## A log of its own

`%AppData%\Nextcalibur\logs`: one file a day, seven kept, events only. "Open
the log folder" is in the tray menu. An error on the interface thread is
logged and shown; the application carries on.

## Taskbar and window

One button whether started from a pin, the Start menu or Windows itself; it
minimises on a second click like any other. Closing the window exits, after
a question; the third caption button hides to the tray. Every question,
including from the tray and the taskbar, is the application's own dialogue.

## Small things

- The CPU & GPU panel shows the card asleep rather than waking it to ask.
- The overheat thresholds can be typed as well as slid, and reset.
- Turkish and English inside the application are on the plan, last.
