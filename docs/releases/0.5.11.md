# Nextcalibur 0.5.11

The graphics mode as it really is, with a monitor plugged in.

## Fixed

- **Hybrid no longer shows as Discrete with an external monitor.** The mode
  was worked out from which chip was drawing a screen, and the HDMI port is
  wired to the graphics card - so a monitor on it made Hybrid read as
  Discrete, and the page offered a switch "back" to Hybrid that would have
  asked for a restart for nothing. The mode now comes from the firmware's
  own answer at start, which only a restart changes: lid open or shut, one
  screen or several, monitors plugged in or pulled out while it runs.
- **UMA with the lid shut** read as "could not work out how your graphics
  are set up"; a switched-off card is UMA whatever the screens are doing.
- **Turning the card off with a monitor on it** is still refused - that
  monitor would go dark - but now says why: unplug the monitor, not
  "switch to Hybrid and restart" when the machine is already in Hybrid.
- **The window came back where nothing could show it** when it had been
  hidden to the tray on a monitor that was then unplugged. It now comes back
  on the main screen.

## Added

- In Hybrid, a note when a monitor is plugged into a port the graphics card
  drives: the card stays awake while it is connected.
