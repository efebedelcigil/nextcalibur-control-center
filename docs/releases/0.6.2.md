# Nextcalibur 0.6.2

Office mode that is actually cool, plan repairs that actually happen, and a
mode for a program while it runs.

## New

- **A mode for a program.** Settings > Program rules: while a program on
  the list runs - MATLAB, an installer, a game - its mode is on, and the one
  before comes back when it closes. Windows says when programs start and
  stop; nothing is polled. A mode chosen by hand while a rule is in force
  wins until that program closes. On battery with "Office on battery" on,
  Office stays. Off until switched on.
- **Each mode's power plan tuned.** The vendor's Office and Gaming plans
  are Windows' Balanced with a different floor or ceiling and nothing else.
  Each mode's plan now also gets its own boost mode, energy preference,
  scheduling between efficient and performance cores, and cooling policy:
  Office quiet and on the efficient cores first, slowing down before the
  fans spin up; Gaming like Balanced with a floor that lets the processor
  rest; Performance eager. Every original is kept and offered back at
  uninstall.

- **Sleep and screen.** Settings > Sleep and screen: when the display
  turns off and the computer sleeps, for every mode in one table, plugged
  in and on battery, and the screen saver. Each row is that mode's power
  plan - the values the Control Panel's plan settings show - so a change
  here is written to Windows and a change in Windows shows here, each mode
  keeping its own. Nothing is changed unless chosen.
- **Asked once about a game played in Office.** When a program that covers
  the screen stayed open in Office for a few minutes, the window asks after
  it has closed whether it should switch to Gaming (or Performance) from
  then on; the answer becomes a program rule, and "No" is not asked again.
  Browsers and video players are never asked about. No game has to be
  added by hand.
- **Nothing about a game comes as a notification.** Windows holds
  notifications back during games, and a borderless game was not even
  recognised as one: heat and the fan-turbo suggestion from that time now
  wait, and are shown in the window as one summary once the game closes.

## Fixed

- **Office ran at full boost.** Office's 70% ceiling held only the
  efficient cores: on a hybrid processor the performance cores have a
  ceiling of their own, which stayed at 100%, so in Office they boosted to
  3.8 GHz and the processor reached 94 °C with little running. Office, and
  *Emergency Office*, now hold both.
- **The plan repairs never happened.** The original of each change was to
  be written beside the plan, where Windows lets administrators only read;
  every write failed, and with it - silently - the repair of the Gaming
  plan's 99% floor and *Emergency Office*'s ceiling. The originals are now
  kept under a key of Nextcalibur's own, removed at uninstall.
- **A display that never turned off.** The vendor's Gaming plan never turns
  the display off when plugged in, so a monitor switched off at its button
  kept receiving frames from the graphics card. Set once to ten minutes; a
  "never" chosen later in Windows' Settings is left alone.
- **Program rules** (before release): a program that has just closed can
  still be listed for a moment, and Windows cuts long names in its start
  and stop events at 15 characters - both handled; a choice by hand no
  longer silences later rules.

## Updated

- **.NET 10.0.13** (security release of 13 October): the System.Management
  and System.Diagnostics.EventLog packages the application carries inside
  it moved from 10.0.12; the release check refused to build with the older
  ones.
