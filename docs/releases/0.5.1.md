# Nextcalibur 0.5.1

The first release to arrive through the update chain - 0.5.0 installed by
hand, this one found and applied by the application itself.

## Overheat warning, per chip

The warning watches the GPU as well as the CPU now, each against its own
threshold: CPU 90 °C and GPU 85 °C by default, both adjustable from sliders
on the System page next to the temperatures they apply to. The tray keeps
the on/off switch. Either chip crossing its line raises one notification;
it does not repeat until both have cooled well below.

## Updates, on your terms

"Check for updates automatically" in the tray menu: on by default, one small
request a minute after start and one every six hours - nothing between, and
off means no request at all. "Check for updates now" beside it says what it
found either way.

## The window's own dialogues

Every question and notice is drawn inside the window now, over a shade that
takes every click, silent, with Escape as the safe answer. Windows' own box
appears only when there is no window to draw in.

## The readings, on every page

The CPU & GPU and Memory & Disk panels sit on every page but Lighting now,
and the overheat switch and thresholds live inside CPU & GPU, on the row of
the chip they apply to. The GPU row shows the card's clock and draw when it
is awake and says "asleep" when it is not - and it no longer wakes the card
to find out. The two-second tick had been reading the GPU clock through
NVML in every mode, which kept the card awake whenever the window was open;
it now asks Windows' own record of the card's power state first, which costs
nothing and wakes nothing.

## Display Mode

An unreachable mode says so on its card - UMA cannot be reached from
Discrete, nor Discrete from UMA, without Hybrid between - and a firmware
switch that is waiting for a restart says so above the cards.

## Small things

- A setting an older version does not know is kept and written back, not
  dropped; 0.4.0 lost the chosen mode this way once.
- The title-bar mark is the application's real icon; the light-theme icon
  has its rays.
- The tests no longer leave the machine starting the test host at sign-in.
