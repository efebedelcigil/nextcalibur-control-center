Nextcalibur Control Center is free, open-source software, developed and
tested on one laptop: a Casper Excalibur G870 (Tongfang JS970). It talks to
your laptop's firmware to read temperatures and fan speeds, set the keyboard
lighting, and switch power and graphics modes. Switching the graphics mode
changes what the TPM measures at startup; the Windows PIN has to be set up
again afterwards, and if BitLocker is on, the next start can ask for the
recovery key.

On a machine that does not have the same firmware interface, Nextcalibur
locks itself and does nothing.
